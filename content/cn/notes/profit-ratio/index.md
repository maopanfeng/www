<strong>从 PE、ROE 到分红修正、周期估值与 Excel 实操</strong>  
整理与分析日期：2026 年 11 月 15 日

市赚率试图回答一个具体问题：面对赚钱能力不同的企业，怎样比较它们的估值？雪球作者 <strong>ericwarn丁宁</strong> 给出的办法，是把市盈率与净资产收益率放在一起，形成 PR 指标，再对分红较低的稳定盈利企业做修正。

这套方法的价值在于让“好公司、好价格”变成可以讨论和复核的数字。它的主要局限也在这里：一个数字容易让人忽略利润质量、增长期限、资本结构和股东真正能够收到的现金。理解市赚率，应当同时理解它算出了什么，以及它省略了什么。

<strong>资料范围说明：</strong>本文整理的是此次能够检索核对的代表性原文及作者回复，包括早期理论稿、系列文章、分红修正说明、周期股方法和近年的使用补充。雪球部分页面直开无正文，核对使用了可检索的原文文本；图片中的全部数据、已删除内容及作者全部历史帖子未能完整取得，因此不能声称穷尽其所有文章。下文明确区分作者观点、数学推导与本文分析。文中的“市赚率”不同于表示市场份额的“市占率”。

## 二、第一公式究竟怎样算

丁宁早期理论稿把 PR 定义为 PE 相对于 ROE 的比值。这里有一个必须统一的约定：口语中的“PE 除以 ROE”，通常把 20% 的 ROE 当成数字 20 来使用。[早期理论稿](https://xueqiu.com/9363345092/110590004)

为避免混淆，本文定义：

- <strong>PE</strong>：市盈率，即市值 ÷ 对应期间归属普通股股东的净利润。
- <strong>r</strong>：小数形式的 ROE，例如 20% = 0.20。
- <strong>R</strong>：百分数去掉百分号后的数字，因此 R = 100r，例如 R = 20。

于是同一个公式可以写成：

```text
PR = PE / R = PE / (100 × r)
```

假设 PE 为 10 倍，ROE 为 20%，则 PR = 10 ÷ 20 = <strong>0.50</strong>。在 Excel 中，如果单元格写的是 20%，必须计算 `PE/(ROE*100)`。直接写 `PE/ROE` 会得到 50，扩大 100 倍。

以下为本文自设的比较例，不是任何公司的实时数据：

| 企业 | PE | ROE | PR | 指标表达的含义 |
|---|---:|---:|---:|---|
| 甲 | 10 | 20% | 0.50 | 每单位 ROE 对应的 PE 较低 |
| 乙 | 10 | 10% | 1.00 | 相同 PE，但净资产盈利能力更低 |
| 丙 | 20 | 40% | 0.50 | 与甲同 PR，但高 ROE 的可持续性须额外核查 |

这个比较说明：PR 不会简单地把所有低 PE 股票都视为便宜。不过，甲与丙同为 0.50，并不能证明它们风险相同、成长机会相同或应有相同回报。

## 三、“1PR 合理、0.5PR 半价”是什么性质的判断

丁宁在多篇文章中把 1PR 作为合理估值参照，并用低于这一水平的价格表达折价买入。他也强调需要遵守估值纪律。[估值与纪律](https://xueqiu.com/9363345092/232098454)

<strong>本文推导：</strong>设目标 PR 为 t，则基础公式对应的基准 PE 为：

```text
基准 PE = t × R
模型基准价 = EPS × t × R
```

如果 ROE 是 20%，t = 1，就相当于给企业 20 倍 PE。当前 10 倍 PE 相对于这个基准是五折。这里的“五折”依赖于先接受“20 倍为合理基准”这一假设。公式本身没有证明该基准。

比如两家公司 ROE 都为 20%，一家能够长期把利润投入高回报的新业务，另一家正在失去客户。模型会先给出相同基准，但两者未来现金流可能完全不同。只有对经营期限和持续盈利作出判断之后，折价才有经济意义。

因此，本文和 Excel 都使用“<strong>模型基准价</strong>”这一名称。0.5PR 是相对于特定模型的折价，不是市场已经被证明低估 50%，也不是未来翻倍的承诺。

## 四、分红修正：为什么相同 PR 还要乘一个 N

丁宁在比较白酒与银行等企业时，引入股利支付率修正。其规则为：支付率不低于 50% 时 N = 1；不高于 25% 时 N = 2；两者之间 N = 50% ÷ 支付率。修正后的 PR 等于基础 PR 乘以 N。[分红修正原文](https://xueqiu.com/9363345092/176294135)

这里的股利支付率 d，指分配的现金股利与对应利润之比。<strong>股利支付率不等于股息率</strong>：前者的分母是利润，后者的分母是股票价格或市值。

| 股利支付率 d | N | 基础 PR 为 0.50 时的修正 PR |
|---|---:|---:|
| 60% | 1.000 | 0.500 |
| 50% | 1.000 | 0.500 |
| 40% | 1.250 | 0.625 |
| 30% | 1.667 | 0.833 |
| 25% | 2.000 | 1.000 |
| 0% | 2.000 | 1.000 |

<strong>本文推导：</strong>如果使用目标修正 PR = t，则：

```text
基准 PE = t × R / N
模型基准价 = EPS × t × R / N
```

这意味着，修正系数上升会降低模型允许支付的价格。例如 ROE = 20%、N = 1.25、t = 1 时，基准 PE 从未修正的 20 倍变为 <strong>16 倍</strong>。

作者后来解释，50% 是其在比较企业分红实践时选择的参照。[修正系数的起源说明](https://xueqiu.com/9363345092/365026405) 本文认为，这个规则把股东现金回报纳入了讨论，但它仍有三项需要主动核查的限制。

第一，低分红可能是资本约束、经营现金流不足，也可能是高回报再投资或回购。原因不同，折价理由不同。第二，高分红可能来自非经常性出售资产、举债或消耗现金储备，不能只看一年。第三，N 在 2 处封顶，使 0% 与 25% 支付率得到同样修正。这个设计保留了简便性，却压缩了两者真实差异。

“赚假钱”是作者的表达，不能直接据此认定某企业造假。判断利润能否变现，仍要检查现金流、应收、资本开支和资本补充需求。作者也明确限制了修正公式的使用范围，提醒不要机械套用于科技、成长和周期企业。[适用范围说明](https://xueqiu.com/9363345092/366503092)

## 五、第二公式：PB 与正常化 ROE

如果利润和净资产使用一致的会计口径，有：

```text
PE = PB / r
PR = PB / (100 × r²)
```

如果 ROE 输入的是数字 R，则等价写法为 `PR = 100 × PB / R²`。第二公式也必须保持百分数约定一致。

<strong>这里的恒等关系有条件。</strong>如果 PB 用的是期末净资产，而 ROE 用的是加权平均净资产，两者不再严格满足上式。PE 采用归母利润、ROE 采用扣非利润，或者一个用年度数据、另一个用 TTM，也会造成差异。不能把行情软件中不同口径的数字凑在一起，再把不一致归咎于模型。

丁宁对周期股和困境反转股的建议，是使用当前 PB，搭配较保守的多年 ROE 或周期相关取值。[2024 年取值说明](https://xueqiu.com/9363345092/290132265)

一旦把当期 r 换成正常化 ROE，这就成为一个新的盈利能力假设，而不再是当期 PE 公式的机械改写。

<strong>本文自设例：</strong>PB = 2，过去五年 ROE 分别为 8%、12%、20%、25%、10%，算术平均为 15%。正常化 PR 为：

```text
2 / (100 × 15%²) = 0.8889
```

若取目标 PR = 1，模型基准 PB 为 100 × 15%² = <strong>2.25</strong>。每股净资产为 10 元时，模型基准价就是 <strong>22.50 元</strong>。

但五年平均不一定代表未来。五年可能没有覆盖完整周期，历史高利润也可能来自已经消失的供给约束。若合理的正常化 ROE 应降至 12%，模型基准 PB 会变为 1.44，基准价降至 <strong>14.40 元</strong>，比原来下降 <strong>36%</strong>。

一般地，第二公式的基准 PB 与正常化 ROE 的平方成正比。在其他条件不变时，ROE 下调 20%，基准价下降 36%。这使得“挑选一个看起来合理的平均数”成为极高影响的判断步骤。

对于暂时亏损、但有依据判断恢复盈利的企业，正常化方法可以作为研究工具；对于净资产为负、重大资产减值尚未确认或商业模式已经失效的企业，得到一个低 PR 并不能解决估值问题。

## 六、历史案例能说明什么，不能说明什么

在系列第 1 篇中，丁宁使用喜诗糖果的 12.5 倍 PE、25% ROE，以及可口可乐两个年份的数据，展示 PR 分别落在约 0.5、0.474、0.326 的情况。[喜诗与可口可乐原文](https://xueqiu.com/9363345092/265953087)

这些数字在本文中仅作为<strong>作者原文采用的数据</strong>，没有重新审计当年的收购价格、会计利润、净资产和投资批次。它们展示了该指标的解释方式，尚不足以证明它就是巴菲特真实使用的决策公式。

原因在于，知道一个成功投资的结果之后，可以找到很多与之吻合的指标。要证明某一指标有预测价值，需要提前固定规则，并在未用于设计规则的样本上检验。只选成功案例，会遗漏失败者、未买入者和不符合公式却成功的企业。

此外，把两次买入的 PR 简单平均为 0.4，与计算整笔投资的加权估值不是同一回事。购买金额、股份数量、财务数据时点都可能影响结果。这个平均可以解释文章中的直觉，不应被当作已经完整复原的交易成本。

## 七、ROE、复利与 PEG：相似之处在哪里

丁宁的系列第 5 篇尝试用 ROE 替代 PEG 中的增长率，并补充了增长、杠杆方面的筛选条件。[PEG 比较原文](https://xueqiu.com/9363345092/266524522)

<strong>本文推导：</strong>假设企业没有外部融资、ROE 保持稳定、留存利润以同样的回报率再投资，净资产增长率可近似写为：

```text
g ≈ r × (1 − d)
```

ROE = 20%、分红率 = 40% 时，留存收益推动的增长约为 <strong>12%</strong>，并非 20%。只有在全部留存、再投资效率不下降等条件下，g 才接近 r。因此，PR 与 PEG 分别采用不同的分母，不能一般性地互换。

如果再假设估值倍数基本稳定，长期收益可以粗略分解为股息收入与每股盈利增长。用来建立直觉的近似式是：

```text
收益直觉 ≈ d / PE + r × (1 − d)
```

以上述 PE = 10、ROE = 20%、d = 40% 为例，得到 4% + 12% = <strong>16%</strong>。这个数没有纳入利润波动、估值变化、税费、分红再投资时点和股本稀释，不是可承诺的年化收益，也不是精确的单期回报恒等式。

若盈利增长 10%，但 PE 从 20 倍降至 15 倍，忽略分红的价格变化为 1.10 × 15/20 − 1 = <strong>−17.5%</strong>。企业增长与股东收益之间，还隔着买入价格和卖出估值。

## 八、市赚率与 DCF 的关系应怎样理解

在 DCF 文章中，丁宁认为某些设定下，PR 与现金流折现结果接近；他还讨论了大致 10%—33% 的 ROE 范围及不同利率环境下的估值阈值。[DCF 讨论原文](https://xueqiu.com/9363345092/266280482)

<strong>本文判断：</strong>“特定条件下接近”可以成立，但不足以证明 PR 普遍等价于 DCF。PR 没有直接列出增长期限、现金分配路径和风险折现率，这些条件实际上被压进了经验基准。

用一个简单的稳定增长股利模型就能看出差异。若下一期 EPS 为 E₁，分红比例为 d，必要收益率为 k，股利永续增长率为 g，且 k > g，则：

```text
价值 = d × E₁ / (k − g)
前瞻 PE = d / (k − g)
```

这是本文用等比数列现值得到的教学推导。假设 d = 50%、g = 5%，当 k = 10% 时，前瞻 PE 为 10 倍；k 上升到 12%，它会降至约 7.14 倍。ROE 即便不变，风险要求变化也会改变合理价格。

因此，不能因为某企业 ROE 为 20%，就对所有市场、时期与风险水平始终给予 20 倍 PE。作者讨论的 ROE 区间也属于适用性提醒，不是一个精确的统计分界线。9.9% 与 10.1% 的公司，不会仅因越过界线就发生估值原理上的突变。

## 九、真正要分析的是低 PR 背后的企业

<strong>利润可能被重复放大。</strong>设市值为 M，利润为 E，权益为 B，并使用一致口径。因为 PE = M/E、r = E/B，所以 PR = M×B/(100×E²)。当利润短暂上升时，PE 下降、ROE 上升，会共同把 PR 压低。市值与权益暂时不变、利润翻倍时，PR 会变为原来的四分之一。这解释了周期顶点为何容易出现看似极便宜的数字。

<strong>高 ROE 也可能来自低权益。</strong>杜邦分解把 ROE 拆成利润率、资产周转率和权益乘数。资产负债率提高、回购减少账面权益，都可能推高 ROE。相同的 20% ROE，可能对应完全不同的经营与融资风险。

<strong>低分红未必摧毁价值。</strong>若企业能把留存资金投入长期高回报项目，减少分红可能提升未来每股价值。反之，低分红伴随低效扩张、关联交易或持续融资，折价就可能有充分理由。需要分析留存资金的用途，而非只按支付率排序。

<strong>银行与实业需要不同的核查重点。</strong>实业应关注利润与经营现金流、维持性资本开支、应收和存货。银行更需要观察资产质量、信用成本、拨备、资本充足和资本补充，不能简单照搬工业企业的现金流判断。

<strong>账面资产可能不代表可实现价值。</strong>无形投入费用化可能让优秀轻资产公司的净资产偏低；资产减值滞后可能让困境公司的净资产偏高。PB 与 ROE 都依赖会计分母，不能脱离财报附注。

<strong>高分红不会自动覆盖股价损失。</strong>股息有助于形成现金回报，但利润恶化、削减分红或估值下降都可能超过股息收入。股息率较高也可能只是股价提前反映了风险。

这些问题应当在计算前判断。计算后的低 PR，可以推动进一步研究，却不能替代研究。

| 单元格 | 指标 | 核心 Excel 公式 |
|---|---|---|
| B6 | PE | `=B18/B19` |

```excel
五年平均 ROE：=AVERAGE(B20:B24)

```

本页不自动套用分红修正，避免把稳定价值股的分红规则直接混入周期股估值。五个年度缺少任何一个时，实际文件会提示补齐，而不自动忽略空白或将其当成零。亏损年份应保留；若平均 ROE 不大于零，则不输出正常化估值。

<strong>文件使用顺序：</strong>先选择适用的工作表，替换蓝字输入；再填写公司、价格日期、财报期间和数据来源；检查 ROE、利润及权益口径；最后查看模型结果。默认算例只能帮助熟悉公式，不能直接用于交易。

## 十一、指数、回测与投资纪律应分开看

丁宁在关于宽基指数的回复中，提出由于成分股类型混合，估值阈值需要区别于稳定价值股，并举出 1.5PR 的高估参照。[指数估值回复](https://www.xueqiu.com/9363345092/355675381/403649910)

本文认为，指数应用首先要解决的是聚合口径。成分股 PR 的简单平均，通常不等于先聚合利润、净资产和市值再计算的指数 PR。亏损股是否剔除、金融股权重、再平衡和历史成分股变动都会影响结果。不能只换一个阈值就跳过这些问题。

作者也转发过相关回测，并在讨论中表示自己对量化回测研究有限。[回测转发与讨论](https://xueqiu.com/9363345092/313426580) 判断一个回测至少应检查：财报是否在当时已经公布，是否使用当时的股票池，是否计入退市和暂停交易，是否包含分红与交易成本，是否在样本外仍有效。

收益率、最大回撤与持有时间应一起报告。最高累计收益不是最终收益，平均年度收益也不是复合年化收益。即便回测有效，也要区分究竟来自低估值、盈利质量、行业偏好、分红暴露，还是 PR 本身带来的额外信息。

作者 2026 年半年总结报告了并不突出的阶段收益，并再次讨论高估卖出的纪律。[半年总结](https://xueqiu.com/9363345092/398482887) 这种经历提醒读者，任何估值策略都可能长期落后。应该预先写下买入依据、估值假设和退出条件；经营事实变化时，优先重估利润与价值，不能只等待原先目标价。

## 十二、把方法转化成可以执行的研究流程

1. <strong>先辨认企业类型。</strong>稳定盈利企业可从第一公式入手；周期企业需要正常化假设；负权益、商业模式失效或高度依赖远期不确定盈利的企业，应换用更合适的分析方式。
2. <strong>建立同口径数据。</strong>固定价格日，明确年度或 TTM，区分归母与扣非、平均权益与期末权益，处理币种与每股基准差异。
3. <strong>解释 ROE 的来源。</strong>把高利润率、周转效率、杠杆、回购和一次性收益分开，判断未来是否能够维持。
4. <strong>解释资本配置。</strong>分红、回购、留存再投资与再融资都要看，确认留存收益是否提高了每股价值。
5. <strong>计算并记录假设。</strong>采用什么正常化 ROE、为什么选这个目标 PR、为什么需要这份折价，均写在计算表旁。
6. <strong>用其他方法交叉检查。</strong>对照现金回报、资产质量及适合行业的估值方法。结果冲突时，回到假设差异，而非简单平均不同目标价。
7. <strong>持续更新经营证据。</strong>利润下降、资本需求上升、资产减值和分红政策改变，都可能使原来的“便宜”消失。

市赚率能帮助投资者把估值判断写下来、算清楚、反复比较。它最值得保留的是对价格和持续盈利能力的共同关注。决定模型是否有用的，最终是输入的 ROE 是否可靠、利润能否成为股东现金，以及为这些不确定性留下了多少价格余地。

*本文是对丁宁公开观点的归纳与独立分析，Excel 为教学计算模板。模型算例不构成任何股票的实时估值或个人投资建议。*
